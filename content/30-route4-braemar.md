# 具体路线 · 宝马山

```meta
tone: free
tag: 实测路线 B
summary: 视野最好 · 需走约 20 分钟山路 · 下山无路灯
```

!!! 这条也不是最优路线。因为小巴上下车位置自由度大，全程**只能给个大致描述**。

!!! 下山**没有路灯**。手电或手机补光灯一定带上。

## 先从金钟站换到天后站

从**福田口岸**（香港那边叫**落马洲口岸**）或者**罗湖口岸**坐**东铁线**到**金钟站**，再换**港岛线**去**天后站**。

```steps
- n: "1"
  title: A1 出口出站，往西走到"天后站公共運輸交匯處"，搭 49M 小巴
  img: assets/img/route4-01-minibus-49m.jpg
  cap: 天后站公共运输交汇处的 49M 小巴，车头显示"天后站 ↔ 寶馬山"
  note: 上车时跟司机说一声**要去宝马山**。
```

## 从下车到登山口

```steps
- n: "2"
  title: 看到"寶馬山花園"就准备下车
  img: assets/img/route4-02-braemar-hill-garden.jpg
  cap: 路边这块"PACIFIC PALISADES 寶馬山花園"石牌，就是该下车的信号
  note: 听司机提醒，或者看到"寶馬山花園"就下。
- n: "3"
  title: 往上或往下走，看你在哪儿下的车
  img: assets/img/route4-03-security-room.jpg
  cap: 找到"保安控制室"（Security Control Room），楼梯就在旁边
  note: 认准这块牌子，从旁边楼梯上去，**一直爬到楼梯消失为止**。
- n: "4"
  title: 找到绿色栅栏
  img: assets/img/route4-04-green-fence.jpg
  cap: 路口对面的绿色栅栏，沿红色箭头方向上去
- n: "5"
  title: 走到这道绿色铁门
  img: assets/img/route4-05-green-gate.jpg
  cap: 认准这道绿色铁闸门，门上贴着公告
```

## 上山

```steps
- n: "6"
  title: 推门
  img: assets/img/route4-06-push-door.jpg
  cap: 门上写着"推 PUSH"，推开就行
  note: 门上有"請順手關門 / Please keep this gate closed"的告示。**进去记得把门带上**，后面还有人要走。
- n: "7"
  title: 进去
  img: assets/img/route4-07-enter.jpg
  cap: 进门后是绿栏杆围着的缓坡水泥小径
- n: "8"
  title: 上山，这一段是台阶
  img: assets/img/route4-08-stairs-up.jpg
  cap: 顺着台阶往上爬，一路都有绿色栏杆
- n: "9"
  title: 岔路选向上的那条
  img: assets/img/route4-09-path-fork.jpg
  cap: 第一个岔路口，挑向上的
- n: "10"
  title: 又是岔路，还是选向上
  img: assets/img/route4-10-fork-up-1.jpg
  cap: 再遇到岔路，照样挑向上的
  note: 这段是连续的石阶，慢慢走，不用赶。
- n: "11"
  title: 继续往上
  img: assets/img/route4-11-fork-up-2.jpg
  cap: 认准路口那块棕色木指示牌（寶馬山道 BRAEMAR HILL ROAD／柏架山道 MOUNT PARKER ROAD／金督馳馬徑 SIR CECIL'S RIDE），沿石阶继续走
- n: "12"
  title: 会路过一个观景亭
  img: assets/img/route4-12-pavilion.jpg
  cap: 途经这座六角观景亭，旁边已经能望见维港
- n: "13"
  title: 走右边那条土路
  img: assets/img/route4-13-dirt-path.jpg
  cap: 岔口选右边的土路，别走左边
- n: "14"
  title: 遇事不决选右边
  img: assets/img/route4-14-keep-right-1.jpg
  cap: 遇事不决选右边
- n: "15"
  title: 遇事不决选右边×2
  img: assets/img/route4-15-keep-right-2.jpg
  cap: 遇事不决选右边×2
- n: "16"
  title: 认准这块指示牌
  img: assets/img/route4-16-signboard.jpg
  cap: 认准"金督馳馬徑觀景台 SIR CECIL'S RIDE VIEWING POINT"这块全景指示牌，上面标了维港两岸的地标
- n: "17"
  title: 到达
  img: assets/img/route4-17-viewpoint.jpg
  cap: 港岛天际线都在眼前
- n: "18"
  title: 再往里走几步
  img: assets/img/route4-18-harbour-view.jpg
  cap: 维港一览无余
- n: "19"
  title: 原路下山
  img: null
  cap: null
  note: 山路没灯，**手电必须带**，也留意一下同行的人脚下。
```
