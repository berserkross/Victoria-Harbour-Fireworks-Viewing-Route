# 具体路线 · 宝马山

!!! 这条路线**非最优**，且因小巴自由度高，路线较复杂，**只作大致描述**。

!!! 下山**山路无路灯**，应提前备好手电装备，注意安全！

## 起点：金钟站换港岛线到天后站

从**福田口岸**（香港方称**落马洲口岸**）／**罗湖口岸**搭乘**东铁线**前往**金钟站**之后，换乘**港岛线**前往**天后站**。

```steps
- n: "1"
  title: A1 出口出站，根据指示向西前往"天后站公共運輸交匯處"（天后站公共运输交汇处），搭乘 49M 小巴
  img: assets/img/route4-01-minibus-49m.jpg
  cap: 天后站公共运输交汇处的 49M 小巴，车头显示"天后站 ↔ 寶馬山"
  note: 上车时跟司机师傅说一声**要去宝马山**。
```

## 从下车到登山口

```steps
- n: "2"
  title: 看到"寶馬山花園"（宝马山花园）就准备下车
  img: assets/img/route4-02-braemar-hill-garden.jpg
  cap: 路边这块"PACIFIC PALISADES 寶馬山花園"石牌就是下车的信号
  note: 随后根据司机提醒下车，**或者在看到"寶馬山花園"之后下车**。
- n: "3"
  title: 向上或下走（取决于下车位置）
  img: assets/img/route4-03-security-room.jpg
  cap: 找到"保安控制室"（Security Control Room），从旁边的楼梯上去
  note: 认准这块**保安控制室**的牌子，楼梯就在它旁边，**一直爬到楼梯消失为止**。
- n: "4"
  title: 找到绿色栅栏
  img: assets/img/route4-04-green-fence.jpg
  cap: 路口对面的绿色栅栏，沿红色箭头方向上去
- n: "5"
  title: 走到这道绿色铁门
  img: assets/img/route4-05-green-gate.jpg
  cap: 认准这道绿色铁闸门，门上贴着公告
```

## 上山

```steps
- n: "6"
  title: 推门
  img: assets/img/route4-06-push-door.jpg
  cap: 门上写着"推 PUSH"，推开即可
  note: 门上有"請順手關門 / Please keep this gate closed"告示，**进去后请把门带上**。
- n: "7"
  title: 进入
  img: assets/img/route4-07-enter.jpg
  cap: 进门后是绿栏杆围着的缓坡水泥小径
- n: "8"
  title: 上山（这一段是台阶）
  img: assets/img/route4-08-stairs-up.jpg
  cap: 循台阶往上爬，沿途都有绿色栏杆
- n: "9"
  title: 遇到岔路优先选向上的那一条
  img: assets/img/route4-09-path-fork.jpg
  cap: 第一个岔路口，选向上的那一条
- n: "10"
  title: 遇到岔路优先选向上的那一条 ×2
  img: assets/img/route4-10-fork-up-1.jpg
  cap: 再次遇到岔路，依旧选向上的那一条
  note: 这一段是连续上行的石阶，慢慢走。
- n: "11"
  title: 继续向上
  img: assets/img/route4-11-fork-up-2.jpg
  cap: 认准路口的棕色木指示牌（寶馬山道 BRAEMAR HILL ROAD／柏架山道 MOUNT PARKER ROAD／金督馳馬徑 SIR CECIL'S RIDE），沿石阶继续上行
- n: "12"
  title: 经过观景亭
  img: assets/img/route4-12-pavilion.jpg
  cap: 途经这座六角观景亭，旁边已能望见维港
- n: "13"
  title: 选择右侧的土路
  img: assets/img/route4-13-dirt-path.jpg
  cap: 在岔口选择右侧的土路，不要走左边
- n: "14"
  title: 遇事不决选右边
  img: assets/img/route4-14-keep-right-1.jpg
  cap: 遇事不决选右边
- n: "15"
  title: 遇事不决选右边 ×2
  img: assets/img/route4-15-keep-right-2.jpg
  cap: 遇事不决选右边 ×2
- n: "16"
  title: 认准这块指示牌
  img: assets/img/route4-16-signboard.jpg
  cap: 认准"金督馳馬徑觀景台 SIR CECIL'S RIDE VIEWING POINT"全景指示牌，上面标出了维港两岸的地标
- n: "17"
  title: 到达
  img: assets/img/route4-17-viewpoint.jpg
  cap: 观景台视野：维港与港岛天际线尽收眼底（图为日落时分）
- n: "18"
  title: 原路下山
  img: null
  cap: null
  note: 山路无路灯，**务必自备手电**，并留意同行者脚下。
```
