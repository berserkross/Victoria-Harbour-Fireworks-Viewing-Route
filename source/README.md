## 为什么 PDF 与 XMind 没有入库

两者体积分别为 148.8 MB 与 146.9 MB，**都超过 GitHub 单文件 100 MB 的硬上限**，直传会：

- 被 GitHub 拒绝推送（单文件 > 100 MB）；
- 即使拆分或改用 Git LFS，也会让仓库膨胀到 300 MB 以上，显著拖慢 `git clone` 与 Pages 构建。

网页实际用到的 28 张图片已经全部提取并压缩进 `assets/img/`（见 `assets/manifest.json` 中每张图的来源记录），因此**阅览攻略并不依赖这两份原始文件**。

## 如果确实要归档

任选其一：

1. **外部网盘**：把 PDF / XMind 上传到网盘，在这里补一行分享链接；
2. **Git LFS**：`git lfs install && git lfs track "source/*.pdf" "source/*.xmind"` 后再提交（需要仓库开启 LFS 配额）；
3. **拆分**：用压缩工具把 PDF 压到 100 MB 以内再提交。
